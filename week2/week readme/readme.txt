Project Title: Student Information System

Introduction

This project is a simple Student Information System developed using C# Windows Forms. It is designed to collect and display basic information about students.

Project Description

The system allows users to enter student information through a graphical user interface (GUI). It includes text boxes, labels, and buttons to make the application easy to use.

Objectives

- To create a simple Windows Forms application using C#.
- To learn how to use Labels, TextBoxes, and Buttons.
- To collect student information from users.
- To display entered information using MessageBox.
- To practice basic programming concepts and event handling.

Features

- Enter student name.
- Enter student ID.
- Enter student age.
- Select student gender.
- Display student information.
- Clear all entered information.

Technologies Used

- C# Programming Language
- Visual Studio
- Windows Forms Application

Conclusion

This project helped me understand the basics of C# Windows Forms development. I learned how to design a graphical user interface, use different controls, and write code to handle user actions.
